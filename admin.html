FULL FACE 管理画面

GitHub連携

この画面での変更はGitHub上の data/ フォルダ内のファイルを書き換えることでサイトに反映されます。 初回のみ、書き込み用のアクセストークンをこの画面に登録してください(下の「初めて使う方へ」を参照)。 トークンはこの端末のブラウザだけに保存され、他には送信されません。

🔗 接続済みです
初めて使う方へ(トークンの作り方)
  1. GitHubにログインし、右上のアイコン→Settings→左下の Developer settings を開く
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access は「Only select repositories」で fullface-hp を選択
  4. Permissions → Contents を「Read and write」に設定
  5. Generate token を押し、表示された文字列(github_pat_...)をコピーして上の欄に貼り付け、保存

いつものオーダー

通常使用するスタメン・打順・守備位置を1件だけ登録できます。「読み込む」を押しても、その場では公開されません。

次戦の基本情報

スタメン(打順)

基本は10人打ちですが、9人や11〜12人にも対応できます。行を追加・削除して人数を調整してください。

ベンチメンバー

監督から一言・連絡事項

任意入力です。空欄の場合、サイトには表示されません。

下書き

今の入力内容を、名前を付けて何件でも下書きとして保存できます。保存・読み込みとも、その場では公開されません。

試合日程

今後の試合予定を登録します。日付・場所・時間が決まっていない場合は空欄のままで「未定」と表示されます。

CSVから試合結果を取り込む

スコア記録表(Googleスプレッドシート)を「ファイル→ダウンロード→カンマ区切り形式(.csv)」で書き出してアップロードすると、 試合結果(results.json)と個人成績・TOP5ランキング(stats.json)をまとめて計算します。 反映前に必ず内容を確認できます。盗塁・投手の勝敗はここでは自動反映されません。

試合結果

どの大会・シーズンの結果か選んでから、試合を追加・編集してください。 勝敗と合計成績(◯勝◯敗◯引分)は得点から自動で計算されます。 イニングごとの得点(2026年度)は、この画面では編集できません(既存のデータは保存時もそのまま残ります)。 2026年度の試合には「⚾ 個人成績を入力」から選手ごとの打席結果を追加できます。 2023〜2025年度の過去データは変更できません。

選手名簿

▲▼で表示順を入れ替えられます。サイトの選手名簿にはこの並び順のまま表示されます。

アクセス状況

公開サイト(index.html)へのアクセスをGoatCounterで計測しています。 公開サイト側にはカウンターは表示されません。同じ人が複数回訪れた場合もそれぞれ1回としてカウントする、シンプルなページビュー(PV)数です。
