GitHub連携

この画面での変更はGitHub上の data/ フォルダ内のファイルを書き換えることでサイトに反映されます。 初回のみ、書き込み用のアクセストークンをこの画面に登録してください(下の「初めて使う方へ」を参照)。 トークンはこの端末のブラウザだけに保存され、他には送信されません。

🔗 接続済みです
初めて使う方へ(トークンの作り方)
  1. GitHubにログインし、右上のアイコン→Settings→左下の Developer settings を開く
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access は「Only select repositories」で fullface-hp を選択
  4. Permissions → Contents を「Read and write」に設定
  5. Generate token を押し、表示された文字列(github_pat_...)をコピーして上の欄に貼り付け、保存

CSVから試合結果を取り込む

スコア記録表(Googleスプレッドシート)を「ファイル→ダウンロード→カンマ区切り形式(.csv)」で書き出してアップロードすると、 試合結果(results.json)と個人成績・TOP5ランキング(stats.json)をまとめて計算します。 反映前に必ず内容を確認できます。盗塁の通算数・TOP5も自動更新されます。投手の勝敗はここでは自動反映されません。

選択した試合だけを修正版CSVで差し替えます。日付・相手名から自動選択しません。

試合結果

どの大会・シーズンの結果か選んでから、試合を追加・編集してください。 勝敗と合計成績(◯勝◯敗◯引分)は得点から自動で計算されます。 イニングごとの得点(2026年度)は、この画面では編集できません(既存のデータは保存時もそのまま残ります)。 記録の訂正はCSV取り込み → 既存試合の差し替えから行ってください。 2023〜2025年度の過去データは変更できません。
